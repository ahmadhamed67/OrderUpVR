ORDER UP VR - test build

WHAT THIS IS
A special copy of the RPCS3 emulator that shows Order Up!! on a big virtual screen in your headset
and turns your VR controller into the game's PlayStation Move wand.

INSTALL
1. Close RPCS3 if it is open.
2. Double-click Install.bat. It finds your RPCS3 and game folders (or asks you for them).
   It creates a new folder called RPCS3-OrderUpVR next to your RPCS3. Your original RPCS3 is not changed.

PLAY
1. Connect the Quest 3 to the PC (Quest Link, Air Link, Virtual Desktop or Steam Link) so you see the PC VR home.
2. Double-click "Play Order Up VR.bat" inside the RPCS3-OrderUpVR folder.
3. The first start takes a few minutes. The game then appears on a large screen in front of you.

CONTROLS (the hand that pulls its trigger becomes the pointing hand)
  Aim the controller at the screen ..... move the pointer
  Trigger ............................... T button
  Grip .................................. Move button (also used on the calibration screen)
  A / B / X / Y ......................... Cross / Circle / Square / Triangle
  Left menu button ...................... START
  Right stick click ..................... SELECT
  Left stick click ...................... put the screen back in front of you
  Right stick up/down ................... screen nearer / farther
  Left stick up/down .................... screen bigger / smaller

IF SOMETHING GOES WRONG
Right-click Collect-Logs.ps1 in the RPCS3-OrderUpVR folder and choose "Run with PowerShell".
It puts a zip on your Desktop. Send that zip back.

REMOVE
Double-click Uninstall.bat.
